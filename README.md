# PicoCatcher Updates (GitHub Pages)

Öffentliche, signierte Updatequelle. **Nur** Inhalte aus „Werkstatt → Updatepakete → Updatekatalog erstellen“ in den Ordner `pico/` legen. Niemals Schlüssel, Sicherungen, NVS-Dateien, Kundendaten oder Community-Testdaten hochladen.

Ablauf je Veröffentlichung:
1. In der Werkstatt `Updatekatalog erstellen` wählen. Ausgabeordner ist ein neuer Ordner, Webadresse `https://<konto>.github.io/<repo>/pico`.
2. Den Inhalt nach `pico/` kopieren. Ältere, versionierte Pakete erst entfernen, wenn kein gültiger Katalog sie mehr nennt (Kunden mit zwischengespeichertem Katalog laden sonst ins Leere).
3. Committen und pushen. Spätestens nach 30 Tagen den Katalog neu erstellen, sonst lehnen die Programme ihn als abgelaufen ab.
